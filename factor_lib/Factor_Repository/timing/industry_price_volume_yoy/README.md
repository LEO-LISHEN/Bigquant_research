# 华泰价量同比择时：研报组合与回测记录

本目录包含两份独立的基础因子脚本：

- `price_log_yoy.py`：价格对数同比序列；
- `cumulative_volume_log_yoy.py`：12 个月累计成交量对数同比序列。

本文档仅记录华泰证券《周期择时 1：华泰价量择时模型》（2016 年 9 月）中这两项序列的组合规则、回测实施条件和报告结果；不增加本项目的仓位映射、选股叠加方式、参数建议或效果推断。

## 研报中的序列定义

设行业 `i` 在月份 `t` 的价格同比序列为 `PL(i,t)`，累计成交量同比序列为 `VL(i,t)`：

```text
PL(i,t) = ln(P(i,t)) - ln(P(i,t-12))
VL(i,t) = ln(Volume_12(i,t)) - ln(Volume_12(i,t-12))
Volume_12(i,t) = Σ[k=t-11,t] Volume(i,k)
```

其中 `P` 为行业指数价格，`Volume_12` 为 12 个月累计成交量。研报称取对数是为了更好观察同比序列趋势。

## 四种组合规则

研报逐月对一级行业遍历；某行业满足对应条件时配置该行业，否则不配置该行业。

| 策略 | 该行业在当月需同时满足的条件 |
|---|---|
| 策略一 | `PL(i,t) > PL(i,t-1)`，且 `PL(i,t) > 0` |
| 策略二 | `VL(i,t) > VL(i,t-1)`，且 `VL(i,t) > 0` |
| 策略三 | `VL(i,t) > VL(i,t-1)`，`PL(i,t) > PL(i,t-1)`，且 `VL(i,t) > 0` |
| 策略四 | `VL(i,t) > VL(i,t-1)`，`PL(i,t) > PL(i,t-1)`，且 `VL(i,t) > 0`，`PL(i,t) > 0` |

因此，策略三只要求价格同比序列改善，并不要求价格同比序列本身大于零；策略四才额外要求价格同比序列大于零。

## 研报的回测实施方式

以下均为研报原文所列的实施条件：

1. 对价量同比择时策略进行滚动测试，每月进行仓位调整；
2. 自 2002 年 1 月起测试；回测区间为 2002 年 1 月至 2016 年 8 月，共 176 个月；
3. 逐月计算成交量同比序列或价格同比序列；
4. 遍历一级行业，符合对应策略条件则配置该行业，否则不配置；
5. 只有当月满足条件、被配置的行业数 **大于 5** 时才调仓；若小于 5，则不配置并保持空仓；
6. 研报同时使用申万一级行业和中信一级行业数据进行测算；申万口径使用 28 个一级行业；
7. 超额收益率、夏普比率使用中债一年期国债到期收益率作为无风险利率计算。

上述实施说明未在该段原文中单独给出“各个满足条件行业之间的权重分配公式”；本文档不补充该公式。

## 脚本与研报规则的关系

当前目录的两个脚本只独立计算 `PL(i,t)` 与 `VL(i,t)`；不在因子脚本中实现策略一至策略四的条件判断、行业配置、最少行业数限制、空仓处理或回测。上述内容保留在本 README 中，作为后续按研报复现时的规则记录。
