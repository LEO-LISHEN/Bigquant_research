# 个股价量同比：选股结果的四种筛选策略

每次原选股策略在月末生成候选股票后，为每只候选股票读取当月的价格同比序列 `PL(i,t)` 与累计成交量同比序列 `VL(i,t)`，并与上月值比较。只有满足相应条件的候选股票才进入最终买入名单。

该规则同时是持仓资格门槛：每月对已有持仓重复判定；原本持有、但当月已不满足相应条件的股票，其下一交易日目标权重设为零并卖出。若停牌、开盘跌停等约束使卖出无法成交，则保留该持仓并在之后的可交易日继续执行卖出目标。因子在月末收盘后形成，买卖目标均在下一个交易日执行。

| 策略 | 候选股票 `i` 在月末 `t` 的保留条件 |
|---|---|
| 策略一 | `PL(i,t) > PL(i,t-1)`，且 `PL(i,t) > 0` |
| 策略二 | `VL(i,t) > VL(i,t-1)`，且 `VL(i,t) > 0` |
| 策略三 | `PL(i,t) > PL(i,t-1)`，`VL(i,t) > VL(i,t-1)`，且 `VL(i,t) > 0` |
| 策略四 | `PL(i,t) > PL(i,t-1)`，`PL(i,t) > 0`，`VL(i,t) > VL(i,t-1)`，且 `VL(i,t) > 0` |

这四种规则不改变原选股因子的计算、排序或候选池形成规则；它们决定候选股票是否可新买入，以及已有持仓是否继续保留。最终持仓权重与空余资金处理由具体策略脚本定义。
